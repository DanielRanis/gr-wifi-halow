# IEEE 802.11 ah (WiFi Halow) PHY Simulation in GNU Radio
(Based on the project: https://github.com/bastibl/gr-ieee802-11)

## Overview

This project focuses on the **implementation and simulation of the IEEE 802.11ah Physical Layer (PHY) using GNU Radio**.

IEEE 802.11ah (Wi-Fi HaLow) is designed for **long-range, low-power IoT communication** in license-free frequency bands below 1 GHz.

## Project

The project develops a **configurable IEEE 802.11ah PHY model in GNU Radio** for studying and evaluating wireless communication performance.

GNU Radio is used to implement and simulate key PHY functions, including:

* Signal generation and processing
* Modulation and demodulation
* OFDM processing
* Channel coding and decoding
* Synchronization
* Wireless channel simulation

The configurable design allows different transmission parameters and channel conditions to be tested.

## Evaluation

The implementation can be used to analyze parameters such as:

* Bit Error Rate (BER)
* Packet Error Rate (PER)
* Throughput
* Signal-to-Noise Ratio (SNR)
* PHY performance under different channel conditions

## Technologies

* **GNU Radio**
* **IEEE 802.11ah / Wi-Fi HaLow**
* **Python / C++**
* **Software-Defined Radio (SDR)**

## Purpose

The project provides a **flexible GNU Radio platform for experimenting with IEEE 802.11ah PHY communication**, with the possibility of extending it toward additional PHY and MAC functionality.
